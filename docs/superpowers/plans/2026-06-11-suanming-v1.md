# 算命应用第一版实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 八字+紫微斗数排盘、豆包大模型解读报告与追问对话、带账号和历史记录的响应式 Web 应用。

**Architecture:** Next.js 15 单体全栈，三层：纯函数排盘胶水层（包 lunar-typescript / iztro）→ API 路由（CRUD + SSE 流式 LLM）→ SQLite/Drizzle 数据层。LLM 密钥只在服务端。

**Tech Stack:** Next.js 15 (App Router, TS), Tailwind CSS, Drizzle ORM + better-sqlite3, better-auth, lunar-typescript, iztro, openai SDK (指向火山方舟), zod, react-markdown, vitest。

**设计文档:** `docs/superpowers/specs/2026-06-11-suanming-app-design.md`

### Task 11: 豆包流式客户端

**Files:** Create: `src/llm/ark.ts`

```ts
import OpenAI from 'openai';
let client: OpenAI | null = null;
function getClient() {
  if (!client) client = new OpenAI({
    apiKey: process.env.ARK_API_KEY,
    baseURL: process.env.ARK_BASE_URL || 'https://ark.cn-beijing.volces.com/api/v3',
  });
  return client;
}
export type ChatMessage = { role: 'system' | 'user' | 'assistant'; content: string };
export async function* streamChat(messages: ChatMessage[]): AsyncGenerator<string> {
  const stream = await getClient().chat.completions.create({
    model: process.env.ARK_MODEL!, messages, stream: true,
  });
  for await (const chunk of stream) {
    const d = chunk.choices[0]?.delta?.content;
    if (d) yield d;
  }
```
